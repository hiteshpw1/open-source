# Simple HTML Website

A beginner-friendly HTML project demonstrating a simple multi-page website. The project includes a home page, a navigation bar example, and a footer example, making it a good starting point for learning basic HTML structure and page navigation.

## Features

- Home page (`index.html`)
- Simple navigation bar (`navbar.html`)
- Simple footer (`footer.html`)
- Navigation links between all pages
- Basic CSS styling
- Beginner-friendly project structure

## Project Structure

```text
.
├── index.html
├── navbar.html
├── footer.html
└── README.md
```

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project directory

```bash
cd <repository-name>
```

### 3. Open the project

Open `index.html` in your preferred web browser.

Alternatively, if you use Visual Studio Code with the Live Server extension, right-click `index.html` and select **Open with Live Server**.

## Pages

### `index.html`
- Serves as the project's home page.
- Provides links to the Navbar and Footer pages.

### `navbar.html`
- Demonstrates a simple navigation bar.
- Contains links to all project pages.
- Includes basic styling and hover effects.

### `footer.html`
- Demonstrates a simple footer.
- Contains links to all project pages.
- Uses a fixed footer layout.
